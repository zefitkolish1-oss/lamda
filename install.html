نزّل لمدا ونصّبهاDownload and install Lamda

لمدا تنوزع مباشرة (مو من Play)، فأندرويد يطلب منك تسمح بالتثبيت مرة وحدة. اختار نوع تلفونك:

Lamda is distributed directly (not via Play), so Android asks you to allow the install once. Pick your phone:

نزّل التطبيقDownload for Android

v2.2.1 · 40.3 MB · SHA-256: a930cab27359075ebb7b67472ccdc80509dda524f0446ab8f839775eb0279b35

نزّل الملفDownload the file

دوس نزّل التطبيق. ينفتح Google Drive — دوس زر التنزيل (السهم) وانتظر يكمل.

Tap Download. Google Drive opens — tap the download arrow and wait for it to finish.

اسمح بالتثبيت من المصدرAllow this source

افتح الملف من الإشعارات أو «مدير الملفات». إذا طلعت رسالة «لأمانك…»: دوس «الإعدادات» وفعّل «السماح من هذا المصدر». (أو: الإعدادات ← التطبيقات ← إدارة التطبيقات ← Chrome ← تثبيت تطبيقات غير معروفة).

Open the file from the notification or File Manager. If you see “For your security…”, tap Settings and enable “Allow from this source”. (Or: Settings → Apps → Manage apps → Chrome → Install unknown apps.)

تجاوز فحص MIUIGet past the MIUI scan

شاومي تسوي فحص أمان — انتظره يخلص، وبعدين دوس «متابعة التثبيت» أو «تثبيت على أي حال». إذا Play Protect سأل: «مزيد من التفاصيل» ← «التثبيت على أي حال».

MIUI runs a security scan — let it finish, then tap “Continue installation” / “Install anyway”. If Play Protect asks: “More details” → “Install anyway”.

اسمح بالإعدادات المقيدة (أندرويد 13+)Allow restricted settings (Android 13+)

إذا ما خلاك تفعّل «إمكانية الوصول»: افتح معلومات تطبيق لمدا ← النقاط الثلاث ⋮ فوك ← «السماح بالإعدادات المقيدة»، وارجع فعّلها.

If Android won't let you turn on Accessibility: open Lamda's App info → the ⋮ menu → “Allow restricted settings”, then try again.

شغّل البداية التلقائيةAllow Autostart

بشاومي: معلومات التطبيق ← «التشغيل التلقائي» فعّله، و«توفير البطارية» ← «بلا قيود» حتى الفقاعة ما تنطفي.

On Xiaomi: App info → enable “Autostart”, and Battery saver → “No restrictions” so the bubble isn't killed.

افتح لمدا وكمّل الإعدادOpen Lamda and finish setup

لمدا تمشيك على كل إذن خطوة بخطوة. تصوير الشاشة ينطلب بس وقت الحاجة.

اسمح بالتثبيتAllow installs

افتح الملف من «ملفاتي» أو الإشعار. إذا رفض: الإعدادات ← التطبيقات ← ⋮ ← وصول خاص ← تثبيت تطبيقات غير معروفة ← اختار Chrome أو «ملفاتي» وفعّل «السماح».

Open the file from My Files or the notification. If blocked: Settings → Apps → ⋮ → Special access → Install unknown apps → pick Chrome or My Files → Allow.

طفّي «المانع التلقائي»Turn off Auto Blocker

بـ One UI 6 وفوك: الإعدادات ← الأمان والخصوصية ← «المانع التلقائي» (Auto Blocker) ← إيقاف. تكدر ترجعه بعد التنصيب.

On One UI 6+: Settings → Security and privacy → Auto Blocker → Off. You can turn it back on after installing.
